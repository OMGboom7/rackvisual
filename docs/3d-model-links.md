## Download-Hinweis

1. Sketchfab-Account erstellen (kostenlos)
2. Modellseite öffnen → **Download** klicken
3. Format **GLB** wählen (nicht GLTF + Texturen, das sind ZIP-Dateien)
4. In RackVisual: Library-Panel öffnen → **GLTF / GLB Upload** → Datei wählen
